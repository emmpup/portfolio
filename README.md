# Emily Misola's Portfolio

A personal portfolio website showcasing front-end development and UX/UI design work.

## 🌟 Overview

This portfolio demonstrates the work of Emily Misola, a Front-End Developer and UX/UI Designer who applies "a developer's logic and a designer's empathy to solve complex problems."

## 🛠️ Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Custom properties, CSS Grid, Flexbox, light-dark() color scheme support
- **JavaScript** - Vanilla JS for interactivity
- **GSAP** - Animation library with ScrollTrigger and SplitText plugins
- **Google Fonts** - Geist font family

## ✨ Features

- **Dark/Light Mode** - Automatic theme switching based on system preferences with manual toggle option
- **Responsive Design** - Mobile-friendly layouts
- **Smooth Animations** - Text reveal animations using GSAP SplitText
- **Sticky Navigation** - Navbar with scroll shadow effect
- **Project Filtering** - Filter projects by category (All, Development, UX/UI Design, Other)
- **Interactive Project Cards** - Hover effects with image scaling and status overlays

## 🎨 Featured Projects

A mobile app for trades workers to record incidents and create reports manually, through recordings, or using an AI chatbot.

- **Role:** Full-Stack Developer
- **Tech:** React Native, Figma
- **Status:** 🚧 Work In Progress

### Music Player

A music player website with playlist management, add/delete functionality, and dark/light mode support.

- **Role:** Front-End Developer
- **Tech:** React, Figma, YouTube API

Promotional posters for a magic event featuring Shin Lim, Derren Brown, and David Copperfield. Each design uses distinct color stories to reflect the performer's artistic persona.
